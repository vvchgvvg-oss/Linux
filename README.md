# سطح مكتب Linux/XFCE الأصلي بواجهة المستخدم المرفقة

هذه حزمة Docker لسطح مكتب **Linux حقيقي** يعمل بواجهة XFCE، مع ترتيب لوحات النظام وأيقونات سطح المكتب والخلفية `custom.jpg` المأخوذة من أرشيف المستخدم. يستخدم الثيم والأيقونات الموجودة في إعداد Linux الأصلي، وليس سطح Windows مرسومًا داخل صفحة ويب. يحتوي Firefox وThunar وMousepad وGalculator. لا توجد قاعدة بيانات أو مساحة تخزين دائمة، ولا تحتوي الحزمة على TypeScript.

## العرض على الهاتف والسلاسة

تستخدم الجلسة دقة 1280×720، وتعرضها في noVNC بوضع `resize=scale` مع جودة 5 وضغط 2 لتقليل حمل البث، وتعطّل مؤثرات تركيب النوافذ. حجم خط واجهة Linux مضبوط على 135 DPI وتكبير Firefox على 140%. في noVNC يمكنك اختيار **Scaling Mode → Local/Scale** لإظهار سطح المكتب الأفقي كاملًا على الهاتف؛ تدوير الهاتف أفقيًا يجعل الرموز أسهل قراءة. سرعة الحركة تتأثر باتصال الإنترنت وموارد مضيف Docker.

## التطبيقات والألعاب

Firefox ومدير الملفات والمفكرة والحاسبة تطبيقات Linux فعلية. من اختصار Terminal يمكن تثبيت حزم Linux باستخدام `sudo apt update` ثم `sudo apt install اسم-الحزمة`؛ صلاحية sudo داخل الحاوية فقط. الملفات والتنزيلات متاحة أثناء عمر الحاوية، وقد تختفي إذا حذف مضيف الاستضافة الحاوية أو أعاد إنشاءها. لا تضم الحزمة قاعدة بيانات أو تخزينًا دائمًا.

يمكن تشغيل بعض برامج وألعاب Linux الخفيفة بحسب توافقها. تطبيقات وألعاب Windows بصيغة `.exe` لا تعمل تلقائيًا، ولا يتوفر تسريع GPU للألعاب الثقيلة. ألعاب المتصفح تعمل في Firefox بحسب الموقع والاتصال.

## التشغيل على الاستضافة

يلزم مضيف يدعم Docker Compose وWebSockets وHTTPS. انسخ `.env.example` إلى `.env`، وغيّر `WEB_USER` وعيّن `WEB_PASSWORD` قويًا وفريدًا لا يقل عن 24 محرفًا، واختر `VNC_PASSWORD` مختلفة من 8 أحرف/أرقام ASCII بالضبط. لا تستخدم القيم التجريبية.

```bash
docker compose up -d --build
```

افتح HTTPS الذي يقدمه مضيفك، وأدخل بيانات البوابة ثم كلمة مرور VNC في noVNC. افتح Firefox من سطح المكتب وسجّل الدخول للكورس يدويًا. منفذا VNC الخام `5901` وnoVNC الداخلي `6080` غير منشورين للعامة؛ بوابة Nginx المحمية هي المنفذ المنشور. لا تشغّل اتصالًا عامًا عبر HTTP.

## الملفات

`Dockerfile` يبني Ubuntu/XFCE والثيم والخلفية الأصلية، و`docker-compose.yml` يشغّل سطح المكتب وبوابة Nginx بلا قاعدة بيانات أو volume دائم. يحتوي `assets/custom.jpg` على خلفية Linux التي وفرها المستخدم، و`desktop-shortcuts/` على اختصارات التطبيقات. تتيح `VNC_GEOMETRY` ضبط الدقة (1280x720 افتراضيًا) و`PORT` ضبط منفذ البوابة (8080 افتراضيًا). ملفات `.ts` و`.tsx` وكلمات المرور الفعلية غير موجودة في الحزمة.
